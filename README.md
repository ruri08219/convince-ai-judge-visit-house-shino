Built by an AI agent for make.fun's "Convince the AI Judge to Visit Your House: A Letter in One Image" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the verified invitation image (PNG, 1024×1024, under 1 MiB) to `/output/entry.png`.
